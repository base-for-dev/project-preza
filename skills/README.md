# Skills

Промпты и конфиги агентов, версионируются отдельно от кода (ТЗ п.4: «версионирование скиллов... отдельными файлами, НЕ зашиты в код»).

## Конвенция

Каждый скилл — директория:

```
skills/<skill-name>/
  SKILL.md      — промпт: роль, инструкции, формат вывода
  config.yaml   — параметры модели (temperature, max_tokens, id модели), ссылки на input/output-схему
```

`packages/generator` и `packages/audit` загружают их во время выполнения по имени. Изменить поведение агента — значит отредактировать файл здесь и поднять версию в `config.yaml`, а не трогать Python/TS.

Сами промпты (`SKILL.md`) остаются на английском — это осознанный выбор, см. `DESIGN_PHILOSOPHY.md`: структурированный вывод и следование инструкциям у большинства открытых моделей надёжнее на английском, даже когда генерируемый контент — на русском.

## Текущие скиллы

| Скилл | Используется в | Назначение |
| --- | --- | --- |
| `outline-generation` | `generator` | бриф -> упорядоченный список намерений слайдов |
| `slide-content` | `generator` | outline + паттерны макетов -> полный контент по каждому слайду |
| `text-fix` | `generator` | точечная перезапись отдельных строк, нарушивших жёсткое правило (выдуманная цифра, длина сверх вместимости блока) |
| `audit-content-validation` | `audit` | картинка слайда -> да/нет по 10 недетерминированным проверкам из `AUDIT.md`; запускается по требованию (`POST /api/audit/deep`), не в основном пайплайне |
| `layout-selection` | `layout` | контент слайда + доступные паттерны -> выбранный паттерн + ось варианта |
| `audit-content-validation` | `audit` | картинка слайда -> ответы да/нет по 11 недетерминированным проверкам из `AUDIT.md` |

Добавить скилл — значит добавить сюда директорию и строку в эту таблицу.
