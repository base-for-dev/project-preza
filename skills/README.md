# Skills

Промпты и параметры агентов лежат здесь отдельными файлами, а не в коде, и версионируются. Изменить поведение агента — значит отредактировать файл в этой папке.

## Устройство

```
skills/<имя>/
  SKILL.md      — промпт: роль, вход, выход, правила
  config.yaml   — version, model, fallback_models, temperature, max_tokens, timeout, output_schema
```

`packages/inference` (`load_skill`) читает скилл по имени во время выполнения. Промпты (`SKILL.md`) остаются на английском: структурированный вывод и следование инструкциям у открытых моделей надёжнее, даже когда сам контент на русском (см. `DESIGN_PHILOSOPHY.md`).

## Версионирование

- `version` в `config.yaml` — обязательное `MAJOR.MINOR.PATCH`. Поднимайте его при любом изменении `SKILL.md` или настроек модели.
- `skills.lock.json` хранит для каждого скилла версию и отпечаток содержимого (промпт + настройки без строки `version`). Тест `packages/inference/tests/test_skills.py` падает, если содержимое изменилось, а версия нет — поведение агента не может поменяться под старым номером.
- После правки: поднять `version`, выполнить `make skills-lock`, закоммитить оба файла.
- Версии всех скиллов записываются в результат каждой генерации (`skills` в ответе `/api/audit`) и видны в интерфейсе; полный список — `GET /api/skills`.

## Скиллы

| Скилл | Кто вызывает | Что делает |
| --- | --- | --- |
| `outline-generation` | `generator` | бриф → план: макет, вывод и секунды на каждый слайд |
| `slide-content` | `generator` | план + вместимость слотов → тексты, таблицы, графики и диаграммы, речь спикера |
| `text-fix` | `generator`, `audit` | точечная перезапись строк, нарушивших жёсткое правило (выдуманная цифра, длина сверх блока или лимита) |
| `source-digest` | `ingest` | материалы задачи (репозиторий, документы, история команды) → фактлист |
| `brand-extraction` | `brand` | брендбук и старые презентации → голос, термины, названия |
| `template-catalog` | `brand` | слайды шаблона → каталог: для чего каждый слайд |
| `audit-content-validation` | `audit` | картинка слайда → да/нет по 10 модельным проверкам из `AUDIT.md`; по кнопке, вне основного пайплайна |

Добавить скилл — значит добавить папку, строку в эту таблицу и `make skills-lock`.
