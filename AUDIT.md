# Аудит

Аудит выполняется внутри пайплайна генерации (`packages/audit`), а не отдельным скриптом постфактум. Каждая сгенерированная колода перед экспортом производит список findings; ниже findings помечены по типу.

## Детерминированные (зависят от данных, один вход → один результат)

Реализуются прямо по IR собранного слайда — без обращения к модели.

**Вёрстка**
- элемент вышел за границы слайда
- два текстовых элемента наложились друг на друга (реальная угроза читаемости; наложения с участием пустых/декоративных фигур или картинок исключены — на живых шаблонах это почти всегда намеренный слой дизайна: иконка на бейдже, лого на плашке, QR-код поверх фото; подтверждено на реальной генерации — 29 наложений, 0 текст-на-тексте, все остальные decorative/by-design)
- текст не поместился в свою рамку
- текст обрезан краем слайда
- элементы не выровнены по направляющим макета
- контент заходит в поля/безопасную зону у краёв
- картинка растянута, пропорции нарушены

**Соответствие шаблону**
- шрифт не из набора шаблона, или гарнитур больше двух
- кегль не из типографической шкалы шаблона
- цвет не из палитры шаблона
- слайд собран не на макете из шаблона
- логотип/колонтитул сдвинуты с заданного положения
- контраст текста к фону ниже 4.5:1

**Плотность**
- больше 6 буллетов на слайде
- буллет длиннее 15 слов
- таблица больше 7 строк или 5 колонок
- больше 5 серий на диаграмме
- слайд заполнен меньше четверти или больше трёх четвертей

**Целостность**
- файл не открывается
- остался текст-заглушка (lorem ipsum, XXX, TODO, «вставьте текст»)
- пустой слайд или слайд с одним заголовком
- слайд оказался картинкой, а не редактируемыми объектами
- у диаграммы нет подписей осей, единиц или легенды
- два слайда дублируют друг друга
- число/процент/сумма на слайде, которых нет в исходном брифе (вероятно выдуманы моделью; проверяется только при наличии брифа)

## Модельные (недетерминированные, VLM судит по картинке слайда, да/нет)

1. Заголовок содержит вывод, а не просто называет тему
2. Содержимое слайда соответствует заголовку
3. Слайд пересказывается одним предложением
4. Каждая цифра/факт на слайде прослеживается до исходных материалов
5. На слайде есть реальный контент, а не только заголовок
6. Картинки/иконки относятся к теме слайда
7. Нет служебного мусора: реплик спикера, кусков промпта
8. Нет опечаток
9. Вся колода на одном языке
10. Каждая строка таблицы / пункт легенды работает на мысль слайда
11. Соседние слайды связаны между собой логически

## Добавление проверок

Новая проверка сначала попадает в этот файл (с обоснованием «зачем»), затем реализуется в `packages/audit`. Проверка без записи здесь не часть аудита — код и документация должны оставаться синхронизированы.
