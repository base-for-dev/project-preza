# Аудит

Аудит — часть пайплайна генерации (`packages/audit`), а не проверка постфактум. Каждая колода, любой из трёх вариантов вёрстки, проходит его до того, как пользователь её увидит. В нём 36 проверок двух видов, и различие между ними принципиальное — оно видно и в коде, и в интерфейсе, и на защите.

| | Детерминированные (26) | Недетерминированные (10) |
| --- | --- | --- |
| Чем проверяют | правила по IR слайда, модель не участвует | VLM (`Qwen3-VL-32B`) смотрит на картинку слайда |
| Результат | один и тот же слайд → всегда одни и те же находки | зависит от модели, «да/нет» + причина |
| Когда запускаются | всегда, внутри пайплайна, за доли секунды | по кнопке «Проверить смысл и факты», вне 5-минутного бюджета |
| Цена | бесплатно | один вызов модели на слайд |
| Можно исправить кнопкой | да, для 19 из 26 | нет — судить о смысле должен человек |
| Где в коде | `checks.py`, `design_rules.py`, `export.validate` | `content_validation.py`, промпт в `skills/audit-content-validation` |

Ориентир для каждой проверки — сам шаблон, а не наше представление о красоте: допустимые шрифты, размеры, цвета, поля, направляющие и диапазон заполнения берутся из его слайдов. Всё, что стоит ровно там, где поставил автор шаблона, проверки не считают нарушением: тесный собственный колонтитул или бледный бейдж — решение дизайнера, а не ошибка генерации. Единственное фиксированное правило — контраст (WCAG).

## Как это выглядит для пользователя

- Найденное подсвечивается прямо на слайде рамкой: жёлтой (по правилам) или фиолетовой (по смыслу).
- Под колодой — панель находок, разбитая на две группы с пояснением, чем они различаются. Клик по находке прокручивает к слайду и оставляет подсветку только её.
- У каждой исправимой находки есть галочка. Пользователь отмечает, что исправить, и жмёт «Исправить выбранное»: сервер чинит только это (`POST /api/audit/fix`), заново прогоняет проверки и показывает, что исправлено, а что нет и почему. «Отменить» возвращает предыдущую версию колоды.
- Полный перечень проверок сервер отдаёт как `GET /api/audit/checks` — из него строятся страница `/generation`, названия находок и эта таблица.

## Детерминированные проверки

### Вёрстка

| Проверка | Что ловит | Кнопка «Исправить» |
| --- | --- | --- |
| `shape_out_of_bounds` | Текст или таблица выходят за границы слайда. Картинки и декор, уходящие за край, — приём дизайна, не ошибка. | блок возвращается внутрь слайда |
| `shapes_overlap` | Два блока с текстом перекрываются там, где стоят слова (а не только их рамки) больше чем на 5% меньшего из них. | нижний блок сдвигается под верхний |
| `text_overflow` | Оценка высоты текста с переносами больше высоты блока; собственные плотные подписи шаблона не считаются. | шрифт уменьшается по шкале размеров шаблона |
| `margin_violation` | Сдвинутый текст ближе к краю слайда, чем шаблон когда-либо ставит текст. | блок сдвигается в безопасную зону |
| `misaligned` | Левый край сдвинутого текста не совпадает ни с одной линией, которой пользуется шаблон. | левый край прижимается к ближайшей направляющей шаблона |
| `image_distorted` | Вставленная картинка показана в пропорциях, отличных от её собственных более чем на 10%. | картинка обрезается по центру до нужных пропорций |
| `low_contrast` | Контраст цвета текста и цвета за ним ниже 4.5:1 (для крупного текста — 3:1), по WCAG. | цвет текста заменяется на самый контрастный из палитры (или чёрный/белый) |

### Соответствие шаблону

| Проверка | Что ловит | Кнопка «Исправить» |
| --- | --- | --- |
| `font_not_in_template` | Гарнитура, которой нет в наборе шаблона. | ставится основная гарнитура шаблона |
| `too_many_font_families` | В колоде больше гарнитур, чем использует сам шаблон (но не меньше двух). | вся колода переводится на основную гарнитуру шаблона |
| `size_not_in_scale` | Размер шрифта, которого нет в типографической шкале шаблона (допуск 0.5 пт). | размер округляется до ближайшего из шкалы шаблона |
| `color_not_in_palette` | Цвет текста или заливки, которого нет в палитре шаблона. | цвет заменяется на ближайший из палитры шаблона |
| `layout_not_from_template` | Слайд собран на макете, которого в шаблоне не существует. | нет — сгенерируйте слайд заново на макете из шаблона |
| `brand_element_moved` | Мелкий элемент, который шаблон закрепляет у края слайда, оказался не на своём месте. | элемент возвращается на место, заданное шаблоном |

### Плотность

| Проверка | Что ловит | Кнопка «Исправить» |
| --- | --- | --- |
| `too_many_bullets` | Больше 6 пунктов в одном текстовом блоке. | лишние пункты после шестого убираются |
| `bullet_too_long` | Пункт длиннее 15 слов. | пункт сокращается моделью `text-fix`; если не вышло — обрезается по границе слова |
| `table_too_large` | Больше 7 строк или 5 колонок. | лишние строки и колонки убираются |
| `chart_too_many_series` | Больше 5 рядов данных. | нет — какие ряды убрать — решает автор |
| `slide_fill_ratio` | Занятая площадь выходит за диапазон, который встречается в слайдах самого шаблона. | нет — баланс — решение дизайнера: сгенерируйте заново или поправьте вручную |

### Целостность

| Проверка | Что ловит | Кнопка «Исправить» |
| --- | --- | --- |
| `file_not_openable` | Структура экспортированного файла нарушена (битые связи, повторные id, части без типа) — PowerPoint предложил бы «восстановить». | нет — сам файл повреждён: экспортируйте заново |
| `placeholder_text_left` | lorem ipsum, XXX, TODO, «вставьте текст». | текст-заглушка стирается |
| `empty_or_title_only_slide` | Кроме титульного и заключительного слайдов: слайд без содержательного текста. | слайд удаляется |
| `slide_is_picture` | Картинка на весь слайд без редактируемого текста и таблиц. | нет — вернуть нечего, текста нет: сгенерируйте слайд заново |
| `chart_missing_labels` | Диаграмма с подставленными данными без подписей осей, а с несколькими рядами — без легенды. | нет — для подписей осей нужны единицы автора |
| `duplicate_slide` | Слайды с тем же заголовком и тем же текстом. | повтор удаляется |
| `unsupported_figure` | Число, процент, сумма или срок на слайде, которых нет в исходных материалах (вероятно, выдумка модели). | выдуманная цифра вырезается из текста |
| `language_drift` | Слайд написан не на том языке, на котором бриф. | нет — сгенерируйте текст заново на языке брифа |

## Недетерминированные проверки (модель)

Один вызов на слайд, структурированный ответ — булево значение и причина на каждую проверку. Реализация: `packages/audit/src/audit/content_validation.py`, промпт: `skills/audit-content-validation`. Картинки слайдов рисует браузер из того же `.pptx`, что скачивает пользователь, и присылает вместе с запросом (`POST /api/audit/deep`), серверный рендерер не нужен. У скилла нет запасных моделей: остальные модели проекта не видят картинок и судили бы вслепую, а отсутствие мнения о слайде честнее выдуманного.

| Проверка | Вопрос к модели |
| --- | --- |
| `title_not_a_conclusion` | Заголовок содержит вывод, а не просто называет тему. |
| `content_off_title` | Содержимое слайда соответствует заголовку. |
| `no_single_point` | Слайд пересказывается одним предложением. |
| `untraceable_fact` | Каждая цифра или факт на слайде прослеживается до исходных материалов. |
| `title_only_content` | На слайде есть реальный контент, а не только заголовок. |
| `image_off_topic` | Картинки и иконки относятся к теме слайда (если их нет — не применяется). |
| `leftover_junk` | Нет реплик спикера и кусков промпта. |
| `typo` | Нет опечаток. |
| `table_row_off_point` | Каждая строка таблицы и пункт легенды работают на мысль слайда (если их нет — не применяется). |
| `disconnected_slide` | Соседние слайды связаны между собой логически. |

«Вся колода на одном языке» когда-то была модельной проверкой; язык брифа определяется кодом, поэтому она стала детерминированной (`language_drift`).

## Тесты самого аудита

- `packages/audit/tests` — у каждой проверки есть случай, где она срабатывает, и случай, где молчит; у каждого исправления — проверка результата и того, что исходная колода не изменена.
- `test_check_catalog.py` следит, чтобы каталог проверок, код и этот файл не расходились: проверка без записи в каталоге, запись без проверки или проверка, не упомянутая здесь, — красный тест.
- `evals/test_unseen_template.py` прогоняет аудит и экспорт на шаблонах, собранных с нуля (4:3 и 16:9, другие шрифты и палитры, имена макетов на других языках): ни один шаг не должен зависеть от того, каким был шаблон.

## Добавление проверки

1. Реализовать в `packages/audit` (правила по IR — `checks.py` или `design_rules.py`).
2. Добавить строку в `packages/audit/src/audit/catalog.py` — название для интерфейса и что именно ловит.
3. Описать здесь (id проверки в обратных кавычках) — тест не пропустит иначе.
4. Если у находки есть однозначное исправление — функция в `packages/audit/src/audit/fixes.py`; если нет — причина в `NOT_AUTOMATIC`.
