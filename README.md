# project-preza

Читает произвольную презентацию как дизайн-систему и переносит на неё новый контент в том же визуальном языке. Без ручной переверстки, без слайдов-картинок — на выходе редактируемый `.pptx`.

```
шаблон + бриф  →  дизайн-система  →  новая колода  →  проаудированный, редактируемый .pptx
```

Сделано под кейс «Цифровой дизайнер презентаций», ЛЦТ 2026 (VK Tech). Полная спецификация: `ARCHITECTURE.md`, `MODELS.md`, `AUDIT.md`.

## Быстрый старт

```bash
git clone <repo> && cd project-preza
pnpm install          # фронтенд
uv sync               # бэкенд + пакеты пайплайна
cp .env.example .env  # вписать ключи inference API

pnpm dev               # apps/web на :3000
uv run --package server uvicorn server.main:app --reload  # apps/server на :8000
```

Требования: Node 22+, pnpm 9+, Python 3.12+, [uv](https://docs.astral.sh/uv/).

## Структура репозитория

| Путь | Что здесь |
| --- | --- |
| `apps/web` | Фронтенд на Next.js — загрузка шаблона, просмотр сгенерированных колод, аудит-UI |
| `apps/server` | Сервис на FastAPI — оркестрирует пайплайн, отдаёт API фронтенду |
| `packages/parser` | PPTX/OOXML → промежуточное представление (IR) |
| `packages/design_system` | IR → дизайн-токены (палитра, типографическая шкала, сетка, паттерны макетов) |
| `packages/generator` | Бриф → outline → контент слайдов |
| `packages/layout` | Контент + дизайн-система → собранный слайд (подбор паттерна, укладка) |
| `packages/audit` | Детерминированные и модельные проверки сгенерированных колод |
| `packages/export` | IR → `.pptx` / `.html` / `.pdf`, только нативные объекты |
| `packages/ir_schema` | Общая JSON-схема промежуточного представления |
| `skills/` | Промпты и конфиги агентов, версионируются отдельно от кода |
| `evals/` | Тесты пайплайна на реальных шаблонах (не тесты для галочки) |

Продуктовые/визуальные конвенции репозитория — в `DESIGN_PHILOSOPHY.md`.
