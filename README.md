## ⬇️ Установка

Самый простой путь — готовый установщик. Ставить Python, Node и терминал не нужно.

| Система | Файл | Как ставить |
| --- | --- | --- |
| 🍎 **macOS** (Apple Silicon) | `Preza-…-mac-arm64.dmg` | Откройте, перетащите **Preza** в «Программы». |
| 🪟 **Windows 10/11** (x64) | `Preza-…-win-x64.exe` | Запустите и пройдите мастер установки. |

➡️ **[Скачать последнюю версию](https://github.com/base-for-dev/project-preza/releases/latest)**

> **Первый запуск.** Установщики пока не подписаны сертификатом разработчика, поэтому система спросит подтверждение.
> **macOS:** правый клик по Preza → «Открыть» → «Открыть» (или `xattr -dr com.apple.quarantine /Applications/Preza.app`).
> **Windows:** в окне SmartScreen нажмите «Подробнее» → «Выполнить в любом случае».

После установки откройте **Настройки → Модель**, выберите провайдера и вставьте ключ — и можно генерировать.

## ✨ Что умеет

- **Разбирает шаблон, а не запоминает его.** Палитра, типографическая шкала, макеты со слотами и их вместимость выводятся из самого файла — на шаблоне, которого не видели, работает так же (это проверяет `evals/test_unseen_template.py`).
- **Пишет колоду по брифу.** План → тексты слайдов, где заголовок — вывод, а не тема; речь спикера под длину выступления; 10–15 слайдов, генерация ≤ 5 минут.
- **Рисует графики, диаграммы и пиктограммы** настоящими объектами PowerPoint: график с данными из брифа, процесс, таймлайн, цикл, иерархия, сетка иконок.
- **Три варианта вёрстки** одной колоды — сжато, стандарт, подробно: не косметика, а другие равноценные дизайны шаблона для тех же слайдов.
- **Аудит с двумя видами проверок** — 26 детерминированных (правила по данным слайда, всегда) и 10 модельных (VLM смотрит на картинку, по кнопке). Исправимые чинятся по галочке.
- **Экспорт** в `.pptx` (только нативные объекты), `.html` (один файл) и `.pdf`.
- **Библиотека шаблонов по разделам** (VK Tech, технологии, финансы, маркетинг, консалтинг, креатив) с поиском и предпросмотром «веером»; можно загрузить свой `.pptx` или целый бренд-пакет (`.zip` с шаблонами, брендбуком, логотипами и шрифтами).
- Промпты и параметры моделей лежат отдельными версионируемыми файлами в `skills/`.

## 🚀 Как пользоваться

1. **Опишите презентацию** и ответьте на короткие вопросы: длина выступления, число слайдов, подача, подробность. Можно приложить материалы (репозиторий, документы, историю команды) или брендбук.
2. **Выберите шаблон** из библиотеки, загрузите свой `.pptx` или оставьте «Авто» — подберём по теме. План можно просмотреть и поправить до генерации.
3. **Получите три варианта** колоды с оценкой длины речи. Под колодой панель аудита: отметьте находки и нажмите «Исправить выбранное» (есть «Отменить») или запустите «Проверить смысл и факты».
4. **Скачайте** `.pptx`, `.html` или `.pdf`.

Страница `/generation` наглядно показывает, как устроена генерация: этапы, бюджет 5 минут, цепочку моделей и список проверок.

## ⚙️ Настройки

Кнопка **Настройки** внизу слева.

| Раздел | Что внутри |
| --- | --- |
| **Модель** | провайдер (OpenRouter, инференс VK, Ollama или LM Studio локально, любой OpenAI-совместимый сервер), адрес, ключ, модель для всех шагов, отдельная модель для проверки по картинкам, своя модель для отдельного шага, режим «только моя модель», таймаут. «Проверить подключение» делает один тестовый вызов, «Список» подгружает модели сервера. |
| **Хранилище S3** | Amazon, Yandex Object Storage, MinIO, Cloudflare R2 и другие. После подключения каждая готовая генерация (запрос и три варианта с аудитом) и ваши шаблоны сохраняются в бакет и переживают закрытую вкладку. |
| **Оформление** | светлая / тёмная / как в системе, акцентный цвет, показ ролей на слайдах шаблона. |
| **Система** | папка данных, установка LibreOffice одной кнопкой (для векторного PDF и серверных превью). |

Ключ и секреты хранятся на вашем компьютере в файле с правами только для владельца и **никогда не возвращаются в интерфейс**. Без подключённого S3 ничего не сохраняется на сервере: чаты и готовые презентации живут на странице, о чём приложение предупреждает.

### 📚 Предустановленные шаблоны

Готовая библиотека шаблонов лежит в публичном хранилище только для чтения и подтягивается при первом запуске (проверяется контрольная сумма каждого файла), новые шаблоны появляются в списке по мере загрузки. Адрес можно заменить через `PREZA_PRESETS_URL`; без интернета доступны три небольших встроенных шаблона. Ваши генерации и загрузки туда **не попадают**. Мейнтейнерам: `evals/publish_presets.py`.

## 🛠 Запуск из исходников

Нужны Node 22+, pnpm 9+, Python 3.12+ и [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/base-for-dev/project-preza && cd project-preza
make setup      # ставит зависимости и создаёт .env из .env.example
# впишите INFERENCE_API_KEY в .env
make start      # API на :8000, веб на :3000 (или на ближайшем свободном порту)
```

Без `make`: `pnpm install && uv sync && cp .env.example .env && pnpm start`.

**Docker:**

```bash
cp .env.example .env   # впишите INFERENCE_API_KEY
docker compose up --build
```

Откройте <http://localhost:3000>. Compose поднимает сервер (с LibreOffice) и веб; данные хранятся в томе `preza-data`.

**Команда `preza`** запускает API и сайт одним процессом и открывает браузер: `uv run preza`. Также: `preza doctor` — что настроено, `preza install-libreoffice`, `preza --data-dir …`.

`make help` показывает остальное: `make test`, `make lint`, `make submission`, `make skills-lock`.

## 📦 Сборка установщиков

Установщики собирает GitHub Actions ([`release.yml`](.github/workflows/release.yml)): **пуш тега `vX.Y.Z`** → сборка `.dmg` (macOS) и `.exe` (Windows) → они прикрепляются к релизу.

```bash
git tag v0.1.0 && git push origin v0.1.0
```

Локально (для своей ОС):

```bash
uv run python desktop/build_backend.py                      # замороженный бэкенд + статический сайт
cd desktop/app && npm install && npx electron-builder --mac dmg   # или --win nsis
```

Готовое лежит в `desktop/dist/`. Иконки и оформление установщиков рисует `desktop/make_assets.py`.

## 🔐 Безопасность

- API принимает запросы только с локальных адресов (`localhost`, `127.0.0.1`); чужие `Origin`/`Host` получают 403.
- Сохранённый ключ модели никогда не отправляется на другой адрес, чем тот, для которого он сохранён.
- Имена шрифтов, идентификаторы шаблонов и файлы из загрузок проверяются на выход за пределы своих папок; размер загрузок ограничен.
- Файлы с секретами создаются с правами `0600` сразу.
- Библиотека шаблонов скачивается только по `https`, с проверкой SHA-256 и размера.

## 🔧 Переменные окружения

Все — в `.env` (образец — `.env.example`); в установленном приложении то же задаётся в «Настройках».

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `INFERENCE_API_KEY` | — | ключ inference API; без него генерация недоступна |
| `INFERENCE_API_BASE` | `https://openrouter.ai/api/v1` | любой OpenAI-совместимый адрес |
| `INFERENCE_REQUEST_TIMEOUT` | `270` | секунд на один вызов модели |
| `INFERENCE_MAX_RETRIES` | `1` | повторов при обрыве соединения |
| `UNSPLASH_ACCESS_KEY` | — | фото Unsplash; без ключа фото ищутся в Openverse и Wikimedia Commons |
| `SOFFICE_PATH` | из `PATH` | путь к LibreOffice (векторный PDF, серверные превью) |
| `PREZA_PRESETS_URL` | публичное хранилище проекта | адрес библиотеки предустановленных шаблонов (только `https`) |
| `PREZA_ALLOWED_ORIGINS` / `PREZA_ALLOWED_HOSTS` | — | дополнительные разрешённые источники и хосты API |
| `SERVER_PORT` / `WEB_PORT` | `8000` / `3000` | порты `make start` |
| `NEXT_PUBLIC_API_URL` | `http://localhost:8000` | где браузер ищет API |

## ⚠️ Ограничения

- **Модели.** Нужен доступ к inference API; без ключа работает только разбор шаблона, вёрстка и аудит уже готовых колод.
- **Диаграммы вместо SmartArt.** Диаграммы — группы обычных фигур (правятся как любые), не настоящий SmartArt. SmartArt из шаблона сохраняется, но не переписывается.
- **Графики только из данных брифа.** Чисел, которых в брифе нет, модель рисовать не вправе: график тогда не строится.
- **Текст не редактируется в превью.** Правки — в скачанном `.pptx`.
- **PDF без LibreOffice** рисуется браузером картинками страниц; с LibreOffice — векторный.
- **Не проверялось в самом PowerPoint.** Структура файла проверяется `export.validate`, вид — рендером; открыть итоговые файлы в PowerPoint стоит перед показом.
- **Экзотика OOXML** (встроенное видео, макросы, SmartArt) не переписывается: остаётся как есть или пропускается с пометкой. Файл шаблона внутри бренд-пакета — до 100 МБ.
- **Установщики не подписаны**, macOS — только Apple Silicon.
