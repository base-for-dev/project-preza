# Изменения

Формат — по релизам, новые сверху. Версии скиллов (промптов) ведутся отдельно: `skills/skills.lock.json`.

## 1.0.0 — финальная сдача

### Добавлено
- Хранилище S3 в настройках: история запросов и результатов, загруженные шаблоны; предупреждение, что без него ничего не сохраняется.
- Настройки модели в приложении: провайдер, адрес, ключ, модель (общая, для картинок, для отдельного шага), проверка подключения, список моделей сервера; локальные Ollama и LM Studio без ключа.
- Экспорт в `.html` (один файл, шрифты и картинки вшиты, речь спикера под слайдами) и `.pdf` (векторный через LibreOffice, иначе рисуется браузером) рядом с `.pptx`.
- Графики (колонки, полосы, линия, круговая, кольцевая) — встроенные объекты PowerPoint с данными; числа только из брифа.
- Диаграммы (процесс, таймлайн, цикл, иерархия, сетка иконок) и 26 пиктограмм — группы обычных фигур, редактируются как любые.
- Аудит: 36 проверок вместо 16 (контраст, поля, направляющие, растянутые картинки, слайд-картинка, макеты и гарнитуры, логотипы, графики, целостность файла); исправляемые чинятся по галочке, с «Отменить».
- Каталог проверок (`GET /api/audit/checks`) — один источник для документации, интерфейса и тестов.
- Версии скиллов: обязательное `version`, `skills.lock.json`, `GET /api/skills`, версии в результате генерации.
- Запуск одним файлом: `docker-compose.yml`, `Makefile`.
- Тест на шаблонах, собранных с нуля (`evals/test_unseen_template.py`).
- `PITCH.md` — сценарий питч-сессии.

### Исправлено
- Генерация всегда укладывается в 5 минут: после этапа текста оставлено 30 секунд на вёрстку, фото и аудит (раньше 10, при трёх параллельных колодах выходило 292 с).
- Проверка смысла и фактов падала в браузере с SecurityError при чтении шрифтового стиля API.
- Речь по слайдам обрезается до бюджета слайда (3-минутный запрос давал 3:54).
- Наложение текста сравнивается по месту, где стоят слова, и с наложениями самого шаблона; пустые слайды посередине колоды больше не появляются; слайд с таблицей, где писатель таблицу не дал, собирается из его же пунктов.
- Автоподбор шаблона читает слова самого шаблона, а не таблицу подсказок под образцы.
- `pnpm start` запускал несуществующий пакет; порт веба сам уходит на свободный.
- Выдуманные сроки («5 лет в Яндексе») считаются непроверенными цифрами.

### Убрано
- Мёртвый код, устаревшие описания в документации, подсказки для конкретных шаблонов.

## 0.2.0 — промежуточный этап

Пайплайн end-to-end, три варианта вёрстки, девять колод, аудит из 16 детерминированных и 10 модельных проверок, запасные модели только Apache-2.0 ≤ 35B, сборка колод для сдачи (`evals/build_submission.py`).

## 0.1.0

Разбор шаблона, дизайн-система, генерация плана и текстов, вёрстка, экспорт в `.pptx`.
