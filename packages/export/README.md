# preza-export

IR колоды -> `.pptx` / `.pdf` с нативными, редактируемыми объектами; проверка структуры файла.

Используется `apps/server`. См. `ARCHITECTURE.md` в корне репозитория — как этот пакет встроен в пайплайн.

| Модуль | Что делает |
| --- | --- |
| `export.py`, `from_template.py` | `export_pptx`: слайды клонируются из файла шаблона (фон, мастера, тема), меняется только содержимое; без шаблона — сборка на пустой презентации по IR |
| `visuals.py` | `ChartShape` -> встроенный график PowerPoint с данными; `DiagramShape` -> группа обычных фигур (процесс, таймлайн, цикл, иерархия, сетка иконок) |
| `icons.py` | 26 пиктограмм из простой геометрии (без файлов и шрифтов), имена — `ir_schema.ICON_NAMES` |
| `validate.py` | `validate(path)`: битые связи, части без типа содержимого, повторные id — то, из-за чего PowerPoint предлагает «восстановить» |
| `render.py` | `pptx_to_pdf` (векторный PDF) и `render_pptx` (PNG слайдов) через LibreOffice; `RenderUnavailable`, если его нет |
| `fonts.py` | шрифты шаблона: вшитые или из Google Fonts, для точных замеров и рендера |

Только формы, которые рисуют все просмотрщики: в пиктограммах нет пресетов вроде «sun» или «heart» — браузерное превью и часть других программ их пропускают. `.html` собирает браузер из того же рендера (`apps/web/app/lib/exportFormats.ts`).
