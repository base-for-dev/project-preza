# preza-design-system

IR -> дизайн-токены (цветовая палитра, типографика) + паттерны макетов по роли слайда.

`extract_design_system(deck)` — точка входа (`src/design_system/__init__.py`):

- `tokens.py` — ранжированная по частоте цветовая палитра и типографика (шрифты +
  шкала кеглей), извлечённые из текстовых run'ов и заливок фигур, уже присутствующих в IR.
- `patterns.py` — группирует слайды по `Slide.layout_name` (собственная ссылка шаблона
  на мастер/макет) и суммирует для каждой группы композицию фигур и нормализованные
  диапазоны bounding-box'ов. Без смысловой разметки («титульный слайд» и т.п.) —
  это задача для LLM дальше по пайплайну, не строковое сопоставление здесь.

Используется `apps/server` (`/api/outline`) и `packages/generator`
(`generate_outline` принимает `list[LayoutPattern]`). См. `ARCHITECTURE.md` в корне
репозитория — как этот пакет встроен в пайплайн, и `tests/test_generalization.py` —
доказательство, что извлечение работает на всех 5 шаблонах в `evals/templates/`
без кода, заточенного под конкретный шаблон.
